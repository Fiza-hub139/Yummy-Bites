# 🍔 Yummy Bites - Fast Food Website

Welcome to **Yummy Bites**, a modern, vibrant, and interactive single-page fast-food web application. Built with responsiveness, interactive ordering, and local currency (PKR) support in mind.

---

## ✨ Features

- **Pakistani Rupees (PKR) Pricing**: All menu items, add-ons, combos, taxes, and grand totals are displayed in Pakistani Rupees (Rs.).
- **Interactive Shopping Cart Drawer**:
  - Live calculations for Subtotal, GST Tax (5%), and Flat Delivery Fee (Rs. 150).
  - Dynamic item quantity increment/decrement and item removal.
  - Promo code support (Use `YUMMY20` for a **20% discount**).
- **Category Menu Filtering**: Instant dynamic filtering for Burgers, Pizzas, Fried Chicken, Sides, Beverages, and Combos without page reloads.
- **Customization Modal**: Click any menu item to view calories, descriptions, and optional add-ons (extra cheese, extra sauce) with instant price updates.
- **Special Combos & Deals**: One-click combo claiming that directly updates the cart.
- **Order Tracking Simulation**: Live order confirmation modal displaying order numbers, delivery time estimates, cash on delivery totals, and live delivery status steps.
- **Responsive & Mobile Friendly**: Optimized layout for smartphones, tablets, and desktop devices with smooth scrolling and dynamic search bars.

---

## 🛠️ Tech Stack & Dependencies

- **HTML5**: Semantic markup structure.
- **Tailwind CSS (CDN)**: Utility-first CSS framework for modern responsive styling, animations, and color palettes.
- **Font Awesome 6 (CDN)**: Iconography for UI elements.
- **Google Fonts**:
  - *Outfit*: Headings & Display titles.
  - *Plus Jakarta Sans*: Body text & typography.
- **Vanilla JavaScript (ES6+)**: DOM manipulation, filter engine, cart state management, and modal toggles.

---

## 🚀 How to Run locally

1. **Clone or Download the Repository**:
   Download the project files to your local machine.

2. **File Structure**:
   Ensure all files are in the same folder directory:
   ```text
   yummy-bites/
   ├── index.html        # Main HTML & JavaScript application code
   └── README.md         # Project documentation
   ```

3. **Open the Project**:
   Double-click `index.html` or open it using any browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
